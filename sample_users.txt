 HOW TO START
─────────────────────────────────────────────────────────────────
  1. npm install              (install frontend dependencies)
  2. cd backend && npm install (install backend dependencies)
  3. cd ..
  4. npm run dev              (starts both frontend + backend)

  Frontend : http://localhost:5173
  Backend  : http://localhost:3001
  Health   : http://localhost:3001/api/health

─────────────────────────────────────────────────────────────────
 NOTES
─────────────────────────────────────────────────────────────────
  • Database file : backend/pos.db  (auto-created on first run)
  • Uploads folder: backend/uploads/ (profile pictures)
  • New users can register from the app — no email verification needed
  • To reset demo data: delete backend/pos.db and restart the server
